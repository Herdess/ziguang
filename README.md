# ziguang

一个用于自动生成随机测试数据的小工具。

## 功能

自动生成 **3 组随机数据**，可用于测试、演示或开发阶段的数据模拟。

## 输出

每次运行会生成三组彼此独立的随机数据。

## FPGA Exact A* 求解器

新增的紫光 FPGA Port-to-Port 精确最短路径工程位于 [fpga-exact-astar/](fpga-exact-astar/)。

该工程实现 Exact A*、8 方向 Directional Potential Heuristic、原双向 Dijkstra 对拍模式、VS Code 构建任务和 Golden 回归测试。
